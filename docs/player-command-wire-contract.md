# Player command wire contract

The native `_callServerOnCommand` and `_doServerOnCommand` fallbacks construct
serverbound `0x012d` through the same typed-argument serializer. The canonical
[native contract](../manifests/player_command_wire_contract.json) records the
binary digest, virtual addresses, field sources and unresolved boundaries.
Its instructions were authenticated against the identified retail PE.
The [command and talk contracts](command-talk-native-contract.md) record the
registration, argument lists and yield behavior of both natives and the `NpcBase`
requests that build the same record from an empty typed stream.

## Dispatch and construction

`_executeCommand` resolves a named descriptor and command control object,
checks bindings, and dispatches the selected descriptor. Native `CommandBlock`
fires `_onCommandEvent`; `CommandNonBlock` fires `_onCommandRequest`. The
[registration contract](command-descriptor-registration.md) joins retained
`0x0132` definitions to their conditional constructors. The actual descriptor
selected by a later execution lookup remains unobserved.

Both Lua callbacks can reach the direct native fallback. That route consumes
the name and command object as envelope inputs and serializes the remaining
arguments from index 2. It inserts no separate scalar command-sheet ID.
The construction contract applies when the relevant callback takes its server
fallback and the native gates pass.

| Application offset | Direct fallback source |
| --- | --- |
| `+0x00` | Self actor object `+0x10`, u32 little-endian |
| `+0x04` | Command control binding reference, u32 little-endian |
| `+0x08` | Self actor object `+0x14`, u32 little-endian |
| `+0x0c` | CRC32 of the complete 128-byte tail, u32 little-endian |
| `+0x10` | Descriptor event-type byte; PE virtual zero-fill initially supplies 0 |
| `+0x11` | 32-byte inline descriptor name |
| `+0x31` | 128-byte typed argument stream |
| `+0xb1` | Seven-byte remainder with no established meaning |

The event-wrapper routes through `0x0075E230` and `0x0075E3A0` have a different
source for `+0x08`: `Event::Base+0x08`. Their mapping in
[combat command emission](../manifests/combat_command_emission.json) must stay
scoped to those wrappers.

## Values and references

Ordinary signed32 integral Lua numbers encode as `00` followed by four
big-endian bytes. Nil encodes as the single byte `05`, including explicit
trailing nil arguments. Numeric zero is therefore `00 00 00 00 00`, and the
currency catalog value 1000001 is `00 00 0f 42 41`. Currency has no separate
native type in this path.

Integral Lua numbers outside the signed 32-bit range take the same tag. The
conversion has no range test and goes through `0x009D6600`, where a nonzero
dword at `0x0137B8E8` selects a 32-bit `cvttsd2si`. Such a value, for example
4294967295, then encodes as `00 80 00 00 00`. A zero dword selects the x87
64-bit truncation and keeps the low dword instead. The dword is written from
the CPUID feature test, and the branch a retail host took was not observed. The
[int argument section](command-talk-native-contract.md#int-arguments) records
the addresses.

Control objects encode as `06` plus a binding-reference dword. Item objects
encode as `07` plus binding reference, slot word and package byte. Adjacent
encoded items with the same reference can combine into counted tag `08`;
scalar and nil values break that adjacency. Two items of reference `R` encode
as `08 R S1 P1 02 S2 P2 0D`, where the final byte is the total length `3*N+7`
and each further item raises `N` and the length by 3. `N` and the length are
`u8` with no cap, so the formula wraps modulo 256 from `N=83`. The leading
reference comes from the control-binding registry; equivalence to a raw actor ID
is unproved.

The finalizer may append tag `09` and two u64 metadata values collected from
item records. This trailer is generated by the serializer, independently of
Lua argument positions. The metadata's server meaning is unresolved. `0f`
terminates the stream, and untouched zero-filled bytes after it are padding.
The manifest records the zero-sentinel collection conditions and exact writer
addresses.

## Boundaries

The first unresolved native input is the descriptor selected by the later
`0x0071CA50` name lookup from player `+0xfc`. The
[registration contract](command-descriptor-registration.md) establishes named
wire definitions and conditional constructors, while retaining the receiving
implementation, runtime globals, handoff, insertion history and lifetime limits.

The native send path gates and queues the record through `0x00DB06A0`.
Server consumption of that queued `0x012d` record is the unresolved server
boundary. Construction proves neither socket transmission nor server
acceptance, mutation, settlement, cancellation, timing or response behavior.
