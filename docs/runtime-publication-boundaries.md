# Runtime publication boundaries

These records distinguish client storage and local consumers from the values
and ordering a runtime publisher must supply. Confidence applies to the
specified observation. An unresolved binding below is a gap in the cited
evidence, not a claim that the behavior never existed.

| <a id="dalamud-selector"></a>Dalamud selector and visuals | Clientbound `0x0010` supplies an unsigned byte. Thus `0` selects group `0`; every value `8..255` disables all eight. The retained Limsa nighttime sweep showed large, red, cracked Dalamud for `0`, with the normal moon above it; `1..7` and `255` showed nothing there. Resource groups are `sgrp_meteor` and `sgrp_meteor117..123` under `sky_celestial`. | [SetDalamud architecture](client-architecture.md#setdalamud-s2c-0x0010-selects-one-of-eight-scene-states); [symbol catalog](../manifests/symbols.json), `BCS-Y-0661`, `BCS-Y-1824`, `BCS-Y-1861/1862`; [native visibility consumers](https://github.com/XIVLegacy/xivl-decomp/blob/69b6945b3f172c547d8c1bcbc8bdc64dc52ef579/docs/resource/ambient-garlean-fleet.md#binary-evidence), `0x0059CA60/0x0062AEB0`. | High static selector/disable range; observed visual limited to the named sweep.
