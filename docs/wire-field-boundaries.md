# Wire field meanings and evidence boundaries

The retail 1.23b contracts below distinguish a client field meaning, a checked
constraint, an unread span on an exact path, and an unresolved value domain.
A producer's cleared bytes establish initialization. They do not establish a
receiver requirement. Capture repetition alone also does not make a value a
required constant.

Offsets are application-relative unless the row names a wrapper, game header,
or decrypted payload. The actor wrapper and game-message header are each
16 bytes. Existing records linked below own the complete field inventories.

## Classification answers

Confidence describes the cited observation. An unresolved meaning remains
unresolved even when its byte width or native read is established.

Remote producer roles, uniqueness, repeated-value provenance and live mutation acceptance remain unresolved. |
| <span id="direct-stream-records"></span>Direct stream records | **Conditional framing constraint; opaque application semantics.** The selected parallel parsers copy selectors `7/8` only when the serialized record length is `0x18`. A `0x18`-byte body plus a `0x10`-byte prefix is a `0x28`-byte record and fails that copy if delivered to this exact branch. This condition does not bind every service to that parser or name the payload words. | `xivl-decomp`: [stream parser pair][stream-parser], Static evidence; [stream receive entry][stream-entry], selected caller gates. | High for the fixed copy comparison. | <span id="group-reference-components"></span>Group reference components | **Full client identity; opaque component meanings.** Group references preserve both dwords of a 64-bit pair, compared high then low. | <span id="music-modes-and-timing"></span>Music modes and timing | **Client operations and bounded capture observations.** The [mode table][music-modes] covers `0..255`. When disabled, it caches the latest song/mode pair and returns before these operations. The complete retained-domain census found 26 requests in 13 members, all modes `1/4`, across 54 authenticated members and 84 admitted connections. | `xivl-decomp`: [Consumed mode values and pending state][music-modes]; [Packet observations][music-census]. | High static and observed-capture confidence within those domains. Battle trigger policy, universal exit delay, audible fades and pause/resume guarantees remain unresolved. Retained modes `1/4` do not prove historical absence of modes `2/3`. |
