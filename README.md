## About

This repository preserves client structures, symbols, signatures, RTTI, and
Ghidra workflow notes supported by cited sources for Final Fantasy XIV 1.23b.
It can be checked out and validated independently. Other XIVLegacy repositories
are research references, not build dependencies.
